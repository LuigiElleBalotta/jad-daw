# UI Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `jad-daw`, a Qt Quick window that opens a `.lpc` project, shows tracks, regions and a mixer, edits them through the Core's JSON commands, plays on the default device, saves, and supports undo/redo and remappable shortcuts.

**Architecture:** The Core stays free of Qt. A C++ bridge (`ProjectController` + three list models) owns the `ProjectHost`, engine, media store and audio device; it learns about changes through a new `ProjectHost` change listener, takes a snapshot with `host.read()` and refreshes the models on the Qt thread. QML reads only from the models and sends only commands.

**Tech Stack:** C++20, Qt 6 LTS (Quick, Quick Controls 2, QtTest, QuickTest) installed with aqtinstall, CMake, existing Core + JUCE audio device, Catch2 for Core tests, Inter font (SIL OFL).

**Spec:** `docs/superpowers/specs/2026-10-07-ui-shell-design.md`

## Global Constraints

- Core (`core/`) must build and pass tests with `-DLPC_BUILD_UI=OFF` and without Qt. The only Core change is the change listener (Task 1).
- QML never mutates data: every edit is a command built by `commandFromJson` / `ProjectHost::submit`. A drag sends exactly one command, on release.
- UI strings in English. Fonts: Inter. Colours, radii, spacing only from `Theme.qml` (generated by `tools/gen-theme.mjs`; never edit it by hand).
- Time units: regions are in ticks (960 PPQ) or microseconds; the UI converts with the project's `TempoMap`. Positions are clamped to `[0, kMaxPosition]` (`lpc/validation.h`, 2^40).
- Paths cross the C++/QML boundary as `QUrl`/`QString` (UTF-8) and become `std::filesystem::path` through `QString::toStdU16String()` on Windows (never `toStdString()`).
- Shortcut modifier: Ctrl on Windows, Cmd (QML `StandardKey` / `Qt.platform`) on macOS. Defaults are Logic's (spec section 6).
- Windows first; every task must also configure and compile on macOS CI. No Apple assets or names.
- Every new Core or bridge behaviour has a test that failed first. QML views are tested with `qmltestrunner` offscreen.
- Licence headers are not used in this repo; keep AGPLv3 in `LICENSE`. Add Qt (LGPLv3) and Inter (OFL) to `THIRD_PARTY.md`.

## Review Focus

1. Opening a project folder whose path has non-ASCII characters or spaces (QUrl to filesystem path), and a folder that is not a project: a clear error, no crash, previous project stays open.
2. No audio device at startup, or the device disappears: the app opens, editing and saving still work, the "audio not running" indicator shows, `play` reports an error instead of hanging.
3. Dragging far outside the timeline (negative, beyond 2^40, NaN from QML): the position is clamped before the command is built; a rejected command leaves the models unchanged.
4. Dropping a WAV that is corrupt, not 48 kHz, 24-bit float, or a duplicate name: error message, project unchanged, no half-copied file left in `audio/`.
5. Rapid commands (fader sweep, repeated undo) and out-of-order snapshots: the UI always ends showing the newest revision; stale snapshots are dropped.

In `project_host.h` add inside the class (public):

```cpp
    // Called on the project thread after every accepted submit/undo/redo and after a rebuild of the audio
    // graph. Keep it short and non-blocking: post to another thread. Replaces any earlier listener.
    std::future<void> setChangeListener(std::function<void(std::uint64_t revision)> listener) {
        return call([this, l = std::move(listener)]() mutable { listener_ = std::move(l); });
    }
    std::uint64_t revision() const { return revision_.load(std::memory_order_acquire); }
```

and private members:

    void notifyChanged();

void ProjectHost::notifyChanged() {
    const std::uint64_t rev = revision_.fetch_add(1, std::memory_order_acq_rel) + 1;

- [ ] **Step 3: Implement `snapshot.h` and the three models**

`makeSnapshot` converts regions to beats: Musical regions `ticks / 960.0`; Absolute regions: `frames = µs * sampleRate / 1e6`, `beats = tempoMap.samplesToTicks(frames, sampleRate) / 960.0`. `bpm` is `tempoMap.tempos().front().bpm`, `beatsPerBar` the first signature's numerator. `missing` is true for an audio region whose media item is absent from the pool or `mediaPresent` returns false.
