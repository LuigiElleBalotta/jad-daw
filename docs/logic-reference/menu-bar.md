# Logic Pro 11.2 menu bar (as seen on 2026-10-09)

Menus of the Tracks window with a project open. Shortcuts: `⌘` Command, `⌥` Option, `⌃` Control, `⇧` Shift. On Windows the clone
maps Command to Ctrl and Option to Alt. A shortcut that I could not read exactly is left out. Items shown greyed in Logic depended on
the selection or the state, and are marked *(dim)*. `▸` = submenu. Not yet captured: the **Logic Pro**, **Window** (partly) and
**Help** menus, the File submenus, and the Edit submenus not listed below.
