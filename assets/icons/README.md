# Icons

Original SVG set drawn for this project (no third-party or Apple artwork).

- Grid 20x20, stroke 1.5, round caps/joins, single colour via `currentColor`.
- Transport glyphs (play, stop, record, rewind, forward) are filled; the rest are outlined.
- `preview.html` renders the whole set (open it in a browser).

Missing from the v0.1 list in `docs/design-system.md` §8: none of the P0 set; still to draw are
glue-variants, snap/grid options, tool-specific cursors and track-type glyphs (audio, MIDI, bus, drums, bass, keys, voice).
